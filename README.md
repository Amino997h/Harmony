# 🎴 Harmony - لعبة الورق الاستراتيجية الملكية (60 كرت)

لعبة بطاقات استراتيجية عربية ملكية تحاكي أجواء الكازينو الفاخر، مبنية بلغة بايثون و Pygame مع محرك صوتي وفيزيائي ديناميكي ودعم الشاشة الكاملة (F11).

---

## 🌟 مميزات اللعبة
- **قواعد لعب فريدة وعميقة:** حزمة 60 ورقة (56 كرت أساسي + 4 كروت جوكر تكتيكية).
- **كروت الجوكر التخريبية (The Sabotage Jokers):** مناورة لقلب كروت الموزع وإفساد استراتيجيات الخصوم مع عقوبة وحظر فوز لحامل الجوكر حتى استخدامه.
- **حركات خاصة ملحمية:**
  - السرقة الانتحارية لليد (All-in Steal) مع كشف تسلسلي ثلاثي الأبعاد لكروت الموزع واهتزاز الشاشة وموجات الصدمة عند الإقصاء.
  - المبادلة العمياء والتضحية باليد (Blind Swap & 3X Single Card Gambit).
- **محرك أنيميشن وفيزياء انسيابي:**
  - طيران قوسي بالستي للكروت (Parabolic Arc) مع ظلال منفصلة ومسار ذيل بريق ذهبي.
  - حيوية مستمرة في الخلفية (ذرات غبار ذهبية طافية، تنفس تموجي للكروت، وبريق معدني يسري على حافة الطاولة).
  - تسليط ضوء مسرحي (Volumetric Spotlight) وسهم ثلاثي الأبعاد لتحديد اللاعب النشط ونغمة رنين خاصة لانتقال الأدوار.
- **خريطة كاشفة لـ 60 كرت:** تعرض البطاقات المكشوفة بنور ساطع والبطاقات المجهولة ببهتان ذكي.
- **دعم ملء الشاشة المتكيف:** F11 / Alt+Enter مع محاذاة دقيقة 100% لإحداثيات النقر.
- **محرك صوتي إجرائي مدمج:** مؤثرات واقعية لحفيف الأوراق، ورنين الفيشات، ومعزوفات النصر والإقصاء.

## 🚀 طريقة التشغيل

### 1. التشغيل المباشر عبر الملف التنفيذي:
يمكنك تشغيل اللعبة مباشرة دون تثبيت بايثون:
```
dist/StrategicCardGame/StrategicCardGame.exe
```

### 2. التشغيل عبر بايثون:
```bash
pip install pygame numpy arabic-reshaper python-bidi
python main.py
```
